Welcome to LLMaker

Quick Start Guide

LLMaker is a tool for designing video game levels for Dungeon Despair with the support of large language models.

Domain Constraints

There are several constraints that the LLM adheres to when trying to process your edit requests. This range from level geomtry constraints to parameters values.

  1. A room and each corridor cell contains a single encounter
  2. Trap can only be added to corridor cells, not rooms
  3. A room must always be connected to at least a corridor
  4. A corridor only connects two rooms together

Tips & Tricks

  • Use keyboard shortcuts to speed up your workflow
  • Do not save levels in the middle of a conversation with the LLM. We recommend saving only after edits to the levels are made.
  • In case something breaks catastrophically, use Ctrl+D to display a JSON representation of the level and include it in a new issue on GitHub!
