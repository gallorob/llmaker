LLMaker User Guide

Introduction

LLMaker is a graphical tool for designing video game levels for Dungeon Despair, powered by large language models (LLMs). It allows you to create, edit, and manage rooms, corridors, and entities (enemies, traps, treasures) in a visual and interactive way.

Getting Started

  1. Launching the App: Start LLMaker and open or create a new level.
  2. Main Window Layout:
    • Previews Panel: Shows the current room, its description, and a map of the level.
    • Actions Panel: Contains chat history, input box, and buttons for editing rooms, corridors, entities, and attacks.
    • Menu Bar: Access file operations (Save, Load, Export), undo/redo, theme switching, and this guide.
  3. Editing the Level:
    • In user mode: use the buttons in the Actions Panel to add, update, or remove rooms, corridors, entities, and attacks.
    • In LLM mode: use the chat box to interact with the LLM for suggestions or to process complex changes.
    • The map and previews update as you make changes.

Domain Properties & Constraints

Level Structure

  • Rooms: Each room has a unique name and description. Rooms are connected by corridors.
  • Corridors: Connect exactly two rooms. Each corridor has a direction and a length (must be within allowed limits).
  • Entities: Rooms and corridors can contain enemies, treasures, or traps (traps only in corridors).

Constraints

  • A room and each corridor cell can contain only one encounter (enemy, trap, or treasure).
  • Traps can only be added to corridor cells, not rooms.
  • Every room must be connected to at least one corridor.
  • Corridors only connect two rooms together.
  • Corridor length and direction must be valid and within specified bounds.
  • Entity properties (e.g., enemy HP, treasure loot, trap damage) must be within allowed ranges.

Entity Properties

  • Enemies: Name, description, species, HP, dodge, protection, speed, and attacks.
  • Traps: Name, description, effect, chance, damage, modifier type/chance/turns/amount.
  • Treasures: Name, description, loot, trapped chance, damage, modifier type/chance/turns/amount.

Advanced Usage & Tips

  • Keyboard Shortcuts: Use shortcuts (e.g., Ctrl+H for this guide, Ctrl+S to save the level) to speed up your workflow.
  • Undo/Redo: Use the Edit menu to undo or redo changes.
  • Switching Modes: Toggle between USER and LLM modes for manual or AI-assisted editing.
  • Theme Switching: Change between light and dark themes in the Options menu.
  • Exporting: Use the Export option to finalize and save your level as a scenario.
  • Debugging: If something breaks, use Ctrl+D to copy the level’s JSON and include it in a GitHub issue.
  • Saving: Avoid saving in the middle of an LLM conversation; save after edits are complete.
  • Validation: The app enforces domain constraints and will prevent invalid changes.
